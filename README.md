# たべたもの記録

食べたものを写真で撮ると、Claudeが料理名とカロリーを読み取って記録するアプリです。
iPhoneのホーム画面から、Claudeアプリを通さずに直接開けます。記録はスマホの中と、Googleスプレッドシートに保存されます。

## 用意するもの

- GitHubアカウント（無料）
- Anthropic APIキー（写真の読み取りに使います。Claudeの有料プランとは別に、使った分だけの料金がかかります）
- Googleスプレッドシート「たべたもの記録」（作成済み）

## 1. GitHubに置いて公開する

1. GitHubで「New repository」を押し、名前を `foodlog` などにして **Public** で作る
2. 「uploading an existing file」から、このフォルダのファイルを全部アップロードして「Commit changes」
3. リポジトリの「Settings」→「Pages」→ Branch を `main`、フォルダを `/ (root)` にして「Save」
4. 数分待つと `https://（ユーザー名）.github.io/foodlog/` でアプリが開けるようになります

APIキーなどの秘密の情報はコードに入っていません（スマホの中にだけ保存されます）。公開リポジトリで大丈夫です。

## 2. スプレッドシートとつなぐ（Apps Script）

1. スプレッドシート「たべたもの記録」を開き、「拡張機能」→「Apps Script」
2. 最初から入っている中身を消して、`Code.gs` の中身を貼り付ける
3. 保存したあと、左の歯車（プロジェクトの設定）→ いちばん下の「スクリプト プロパティを追加」で、
   プロパティ `TOKEN`、値に自分だけが知っている合言葉を入れて保存（合言葉はコードには書きません）
4. 右上の「デプロイ」→「新しいデプロイ」→ 種類で「ウェブアプリ」を選ぶ
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」を押し、Googleアカウントへのアクセスを許可する（「安全ではないページ」と出たら「詳細」→「移動」）
6. 表示された「ウェブアプリのURL」をコピーしておく

「全員」にしても、合言葉を知らない人は書き込めません。

## 3. APIキーを作る

1. https://console.anthropic.com にログイン
2. 「Billing」でクレジットを購入（少額で大丈夫です）
3. 「API Keys」→「Create Key」で作ったキー（`sk-ant-` で始まる）をコピー

## 4. iPhoneに入れる

1. **Safari** で `https://（ユーザー名）.github.io/foodlog/` を開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面のアイコンから開き、右上の歯車で次を入れて「保存する」
   - APIキー
   - 連携URL（手順2でコピーしたURL）
   - 合言葉（手順2で決めたもの）
4. 「スプレッドシートとの接続を確認」で「つながりました」と出れば完了

## 使い方

- 下の緑のボタンで写真を撮る（アルバムからも選べます）→ 写真を確認して「読み取る」→ 内容を確認して「記録する」
  （「Sonnetで読み取る」と「Haikuで読み取る」を選べます。設定の「精度」で選んだほうが上に出ます）
- 朝食・昼食・夕食・間食を選べます（時刻から自動で選ばれます）。それぞれを1食として数えます
- 今日の合計の下に「残り◯kcalで食べられそう」な食事の案が出ます。タップするとその内容で入力画面が開きます
- 設定の「筋トレした分を目安に足す」をONにすると、筋トレした日はその消費カロリーの分だけ目安が増えます（そのあいだ、ふだんの活動は自動で「ほとんど座っている」として計算します）
- 1日の終わりに「今日の摂取カロリーを確定する」を押すと、その日の合計が確定します（過去の日は一覧の見出しから）
- 設定の「ドーパミン中毒のガキ向け演出」をONにすると、目安以内で確定したときに派手な演出と効果音が出ます（効果音はマナーモードでないときだけ）
- 設定の「今月の読み取り」で、APIの使用量と金額の目安が見られます
- 写真がないときは「手入力」から入れられます（AIは使いません）
- 料理名を入れはじめると、カロリーの候補が出ます。「前回」は自分の過去の記録、「目安」は一般的な1人前の量です
- グラム数を変えると、カロリーもその量に合わせて変わります
- たんぱく質・脂質・炭水化物・糖質は、写真のときはClaudeが推定します。手入力のときは品目の「栄養素」を押すと入れられます（入れなくても大丈夫です）
- 記録をタップすると修正・削除できます。スプレッドシートにも反映されます
- 電波がないときはスマホに保存しておき、つながったときにスプレッドシートへ送ります（写真の右上に黄色い点が付いている記録が未送信です）
- Safariで使っていた内容をホーム画面のアプリに移すときや、機種変更のときは、設定の「引っ越し」を使います。
  移す前の画面で「引っ越し用にコピー」→ 移した先で「貼り付けて取り込む」。APIキーなどの設定と、写真を含む記録がそのまま移ります
  （機種変更のときは、コピーしたものをAirDropのメモなどで新しいiPhoneに送ってから貼り付けます）
- 体重カードの「＋ 記録」で体重を入れると、折れ線グラフになります（目標体重は破線、順調なときの目安は点線。日・週・月・年で切り替え）。スプレッドシートの「体重」シートにも入ります
- 設定の「からだ」に性別・生まれた年・身長・活動・目標体重を入れると、1日の目安カロリーが出て、トップに「今日 / 目安」で表示されます
- 筋トレの消費カロリーは、時間・強さ・体重からの目安です（時間を入れないときは1セット3分で計算）
- 上の「筋トレ」に切り替えると、筋トレの記録ができます。「＋ トレーニングを記録」→ 種目を選んで、重さ×回数をセットごとに入れます
  （前回の記録が出て、そのままの重さ・回数が入ります。「＋ セット」は直前のセットと同じ内容で増えます）。スプレッドシートの「筋トレ」シートにも入ります
- 体重カードの下の「顔・体の記録」で、顔と体の写真を記録できます（任意）。横にスクロールして日付順に見られ、タップすると大きく表示して左右に見比べられます。この写真はGoogleドライブの「たべたもの記録の顔・体」フォルダにも保存され、「スプレッドシートから記録を読み込む」で戻せます
- 写真はGoogleドライブの「たべたもの記録の写真」フォルダにも保存されます（ファイル名は日時と料理名）
- 「スプレッドシートから記録を読み込む」でも記録を戻せます。写真もドライブから戻ります

## アプリを更新したとき

GitHubのファイルを差し替えると、次に開いたときに新しい版になります。反映されないときは、アプリを一度閉じてから開き直してください。
